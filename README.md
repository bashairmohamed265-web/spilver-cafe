# سبيلفر | Spilver Café

موقع كافيه سبيلفر: صفحة وحدة سينمائية، فوقها فيديو إسبريسو ينقط من أعلى الصفحة وينسكب في الكوب مع التمرير، وتحتها قصة الإخوة الخمسة والمنيو والفروع.

> خمسة إخوة، جمعتهم القهوة وصنعوا منها حكاية.

## التشغيل على جهازك

تحتاج [Node.js](https://nodejs.org) فقط، بدون `npm install`:

```bash
cd frontend
npm run dev
```

بعدها افتح الرابط اللي يطلع في الطرفية (عادة `http://localhost:5173`) في Chrome.

> لو فتحت `index.html` مباشرة بالدبل كلك، يظهر مشهد ثابت مكان الفيديو، لأن المتصفح يمنع تحميل الفيديو من ملف على الجهاز. هذا متوقع.

## محتوى المشروع

```
frontend/
├── index.html       الموقع كامل: HTML و CSS و JavaScript في ملف واحد
├── assets/          الفيديو والصور والشعار
├── package.json     أمر npm run dev
└── dev-server.mjs   سيرفر محلي صغير للمعاينة، بدون أي مكتبات
```

## الأقسام

- **الواجهة:** فيديو يتحرك مع التمرير للأمام والخلف، والجمل تظهر في وقتها.
- **قصتنا:** مع لحظة تفاعلية، تضغط مطوّلًا فتنسكب خمس خيوط فضية في فنجان واحد.
- **الأكثر طلبًا** و**المنيو** بأقسامه الأربعة.
- **أجواء سبيلفر** و**فروعنا** في جدة.
- **انضم إلى فريقنا** و**تابعنا**.
- عربي وإنجليزي بزر واحد.

على الجوال يظهر مشهد ثابت مصمم بدل الفيديو، عشان يبقى الموقع خفيف وسريع.

## للنشر

الموقع ملفات ثابتة: ارفع محتوى مجلد `frontend` ما عدا `package.json` و `dev-server.mjs`، لأنهم للمعاينة المحلية فقط.
