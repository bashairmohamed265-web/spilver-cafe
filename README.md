# سبيلفر | Spilver Café

موقع كافيه سبيلفر، ومعه قاعدة بيانات للمنيو وصفحة إدارة تعدّل الأسعار وتضيف الأصناف بدون ما نلمس الكود.

> خمسة إخوة، جمعتهم القهوة وصنعوا منها حكاية.

## المشروع قسمين

| المجلد | وش فيه |
|---|---|
| [`frontend`](frontend/) | الموقع نفسه: الصفحة الرئيسية بفيديو التمرير، وصفحة الإدارة `/admin`. ([الشرح](frontend/README.md)) |
| [`bachend`](bachend/) | قاعدة بيانات المنيو على Supabase: الجداول والحماية والأصناف. ([الشرح](bachend/README.md)) |

## كيف يتربطون

```
الزائر  ──►  الموقع (frontend)  ──يقرأ المنيو──►  Supabase (bachend)
أنتِ    ──►  صفحة /admin        ──تعدّل المنيو──►  Supabase (bachend)
```

الموقع يعرف مكان قاعدة البيانات من ملف واحد: `frontend/frontend/config.js`.

## التشغيل على جهازك

```bash
cd frontend/frontend
npm run dev
```

بعدها افتحي `http://localhost:5173` للموقع، و `http://localhost:5173/admin` لصفحة الإدارة.

## ملاحظة

سبيلفر مشروع تجريبي. الصور والفيديو مولّدة بالذكاء الاصطناعي، والحسابات وأرقام التواصل للعرض فقط.
