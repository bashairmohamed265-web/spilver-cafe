# الباك اند: قاعدة بيانات المنيو

هنا كل شغل قاعدة البيانات لموقع سبيلفر، وهي على [Supabase](https://supabase.com).

قاعدة البيانات تحفظ أصناف المنيو وأسعارها. الموقع (في مجلد `frontend`) يقرأ منها، وصفحة الإدارة (`/admin`) تعدّل عليها.

## الملفات

```
bachend/
└── supabase/
    ├── setup.sql       جدول المنيو، والحماية، والـ 19 صنف الحالية
    └── add-admin.sql   يخلي حسابك مسؤول عن المنيو
```

## التجهيز (مرة وحدة)

1. **الجداول:** في لوحة Supabase افتحي **SQL Editor** ثم **New query**، والصقي محتوى `setup.sql` كامل، واضغطي **Run**.
2. **حسابك:** من **Authentication** ثم **Users** ثم **Add user** ثم **Create new user**، اكتبي إيميلك وكلمة سر تختارينها بنفسك، وحطي صح على **Auto Confirm User**.
3. **صلاحية الإدارة:** افتحي `add-admin.sql`، وغيري الإيميل اللي فيه لإيميلك، والصقيه في SQL Editor واضغطي **Run**. لازم يطلع لك إيميلك في النتيجة.
4. **اقفلي التسجيل:** من **Authentication** ثم **Sign In / Providers**، طفّي **Allow new users to sign up**، عشان محد يقدر يسوي حساب.

## الربط مع الفرونت اند

الموقع يعرف مكان قاعدة البيانات من ملف `frontend/frontend/config.js`، وفيه شيئين:

- `url`: رابط المشروع (`https://xxxxx.supabase.co`)
- `anonKey`: المفتاح العام (**anon public** أو **publishable**)

المفتاح العام مصمم يكون ظاهر في الموقع، واللي يحمي البيانات هي قواعد الحماية في `setup.sql`: أي أحد يقرأ المنيو، والتعديل للمسؤولين بس.

> ⚠️ المفتاح السري (**service_role** أو **secret**) لا ينحط في الموقع ولا في GitHub أبدًا.

## مين يقدر يسوي وش

| | يقرأ المنيو | يضيف ويعدّل ويخفي ويحذف |
|---|---|---|
| زائر الموقع | ✓ الأصناف الظاهرة بس | ✗ |
| حساب مسجل بس مو مسؤول | ✓ الأصناف الظاهرة بس | ✗ |
| المسؤول (موجود في جدول `admins`) | ✓ كل الأصناف | ✓ |
